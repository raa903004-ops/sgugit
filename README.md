**Работающая версия, развёрнутая командой:** http://51.250.44.9/

**Планируемый адрес GitHub Pages:** https://raa903004-ops.github.io/sgugit/

## Публикация

В репозитории настроена GitHub Actions-задача, которая получает **статическую сборку уже развёрнутого AutoChoice** с сервера команды, проверяет базовые файлы и публикует на GitHub Pages. Она не исполняет Python-бэкенд; рекомендации текущего MVP выполняются в браузере.

Для первоначальной публикации открой **Settings → Pages → Build and deployment → Source: GitHub Actions**, затем запусти **Actions → Deploy AutoChoice to Pages → Run workflow**.

Исходный проект адаптирован также в отдельный архив `AutoChoice_GitHub_Pages_READY.zip`, который содержит `src/`, `backend/`, `public/` и готовый сайт в `docs/`. Для полноценного хранения исходников этот архив следует распаковать в репозиторий (не оставлять единственным ZIP-файлом).

Ограничение: если IP-сервер недоступен, обновить зеркало GitHub Pages через workflow не получится.
